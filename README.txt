DÉPANNAGE.DZ — Prototype Android/Web

هذه النسخة واجهة أولية قابلة للتجربة على الهاتف (PWA):
- طلب النجدة
- قطر السيارات والشاحنات
- ورشة متنقلة
- قطع الغيار
- مقدمو الخدمة القريبون
- أرقام الاتصال
- التقييمات
- واجهة عربية RTL

ملاحظة: البيانات الظاهرة في هذه النسخة تجريبية وليست بيانات مقدمي خدمة حقيقيين.

الربط مع الـBackend:
الـBackend المرفق في المشروع يحتاج PostgreSQL + PostGIS وإعدادات بيئة صحيحة قبل ربط التطبيق به.

لبناء APK لاحقاً:
يحتاج المشروع إلى Android SDK/Gradle في بيئة بناء Android. هذه البيئة الحالية لا تحتوي Android SDK، لذلك لم يتم الادعاء بإنتاج APK غير مبني.
